PORTFOLIO2K26 – WordPress Portfolio

About the Project

Portfolio2k26 is a personal portfolio website developed using WordPress. It showcases personal information, educational background, skills, projects, and team members in one interactive and organized platform.

It allows visitors to explore the portfolio and learn more about the owner's background, abilities, and work.

Main Features and Functions

- **Responsive Design** – Displays properly on different screen sizes and devices.
- **Homepage** – Introduces the portfolio owner through an animated welcome section.
- **About Section** – Presents personal information and background.
- **Education Section** – Showcases educational background and achievements.
- **Skills Section** – Displays skills and areas of expertise.
- **Team Profiles** – Shows team members, including their skills and detailed profiles through the See More feature.
- **Project Gallery** – Displays projects with images and descriptions.
- **Project Details Modal** – Allows visitors to view project information and images without leaving the homepage.
- **Image Gallery Slider** – Lets visitors browse project images using next and previous controls.
- **Dark and Light Mode** – Allows visitors to switch between different website themes.
- **Contact Section** – Displays contact information and ways to reach the owner.
- **Interactive Animations** – Includes scrolling effects, animated elements, and visual effects.

WordPress Customization

The theme also includes an admin editing feature that allows authorized administrators to:

- Edit portfolio text and content.
- Replace profile and project images.
- Update contact information.
- Customize portfolio content through the WordPress Dashboard and Customizer.
- Use the Visual Portfolio Editor to edit text and images directly from the page preview.
